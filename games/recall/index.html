Recall: Daily Pattern Memory Game

Recall is a visual memory game in Puzzle Lantern. A pattern appears on a grid for a short time. When it disappears, tap the cells that were highlighted. Later rounds ask you to remember bigger patterns with less time to look.

Free to download for iPhone and iPad. See the app for current access and subscription options. Android is not available yet.

How to play Recall

  1. Watch the highlighted cells while the pattern is visible.
  2. Remember where the cells sit relative to the edges, corners and each other.
  3. Once the pattern disappears, tap the cells you saw.
  4. Complete the pattern to move to the next round. A mistake ends the run.

A quick example

Imagine three highlighted cells forming an L in the top-left corner. Remembering the L and its position gives you a shape to rebuild when the grid goes blank, instead of three unrelated locations.

Tips for your first game

  • Look for groups such as lines, corners and small shapes.
  • Use the grid edges as landmarks to distinguish similar patterns in different positions.
  • Take a moment to recall the whole pattern before tapping the first cell.

The Daily and more puzzles

Everyone gets the same Daily challenge for that puzzle date. Compare your result with friends, or choose More puzzles for another run. Recall is a game for entertainment; its score is not a measurement of memory ability.
